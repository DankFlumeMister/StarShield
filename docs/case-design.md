## 2. 参数（脚本里叫 `P`，改这里即可）

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `wall` | 2.0 | 侧壁厚（G2 的 2 mm 下限） |
| `floor` | 2.5 | 底板厚 |
| `clearance` | 0.3 | 内腔相对板边单边间隙 |
| `depth` | **15.0** | 板下净空 = 插拔座 3.5 + 电池 10.5 + 余量 1.0 |
| `lip` | 4.5 | 侧壁高出 PCB 上表面（给连接器开孔留料） |
| `boss_od` / `boss_pilot` | 5.0 / 1.7 | M2 自攻柱外径 / 底孔（深 8） |
| `bat_inset` | 8.0 | 电池仓相对内腔边的内缩（避开 φ5 螺丝柱） |
| `seam_x` | **189.70** | 分件缝 = 第 10 列键边界 `x = 4 + (10−0.25) × 19.05` |

⇒ **外形 379.31 × 155.66 mm、总高 23.60 mm**；两件跨度 A 192.0 / B 187.3 mm（打印床 256 ✓）。

预检：`python docs/_tools/preflight_case.py` —— 校验尺寸自洽、净空是否够、8 柱是否落在壳内、
电池仓/压边是否与柱相撞、三处开孔是否落在对应侧壁、分件缝是否穿过柱或电池。**当前全绿。**

## 3. 脚本能建出什么（v1 范围）

底壳（两件）+ 内腔 + **三处侧壁开孔**（做成**顶部开口的槽**：打印机友好，且不必赌连接器精确高度）
+ **8 个 M2 自攻柱与底孔** + **左右两个电池仓压边**（每条边两条压臂，压边高出电池 2 mm）。
导出：`StarShield-case.step`（整件）、`StarShield-case-A/B.stl`（分件）、`preview-iso.png`（视口截图）。

**v1 刻意不做**（都需要先定案，见 §6）：定位板的承托与压边、上盖/边框、脚垫与倾角、
电池引线走线槽、外壳与 PCB 的防呆。

## 4. 怎么运行（**手动一步**）

Fusion 没有进程外 API —— 脚本必须在 Fusion 进程内跑，因此**只能**通过它的入口触发。

**⚠️ 两个先决条件（2026-09-21 实测踩过）**
1. **「实用程序」标签只在打开了一个设计文档时才出现** —— 停在**主页（Home）**是找不到它的。
   ⇒ 先在主页点「新建... → 零件设计 → 新建」，进入工作区后工具栏最右侧就有「实用程序」。
2. **脚本必须放在 `%APPDATA%\Autodesk\Autodesk Fusion 360\API\Scripts\<名>\`**。
   放到同级的 `MyScripts\` 里，**「脚本和加载项」对话框里看不到它**（首版就放错了）。

**步骤**
1. 打开 Fusion 360，进入任一设计（或按上面第 1 条新建一个零件设计）。
2. 工具栏最右 **实用程序（Utilities）→ 脚本和加载项（Scripts and Add-Ins）**；
   快捷键 **`Shift+S`** 更快（实测有效）。
3. 对话框里：若「搜索」框有残留文字先清掉（点 ×）；在**脚本**列表里找到 **StarShieldCase**
   → 点它那一行的 **▶（运行）**。
4. 完成后看 `hardware/case/out/build.log`（逐步日志 + 每步体积自检）与 `out/` 下的 STEP/STL/预览图。

部署/更新脚本：`python docs/_tools/deploy_fusion_addin.py`（装到 `API\Scripts\` 与 `MyScripts\` 两处；
`--remove` 卸载）。

## 5. ⚠️ 踩过的坑（Fusion 自动化事实，供后续复用）

1. **Fusion 没有进程外 API**，也没有命令行执行脚本的开关 ⇒ 想自动化只能在启动时挂钩子，
   或者模拟输入点击。**不存在** headless/batch 模式。
2. **`runOnStartup: true` 的 add-in 机制是真的**（依据：安装目录里多个内置 add-in 清单都用它，
   路径 `%APPDATA%\Autodesk\Autodesk Fusion 360\API\AddIns\<名>\<名>.manifest`）。
   实测**确实自动跑起来了**（重启后 45 秒写出日志）。
   ❗ **但不要在启动阶段做重活**：Fusion 启动初始化尚未完成时建模，会把 Fusion 跑崩
   （崩溃报告落在 `%LOCALAPPDATA%\Autodesk\CER\`）。
3. **首版脚本自身也不稳**：每个小体都新建「构造平面 + 草图 + 拉伸」，8 柱 + 8 底孔 + 24 个压边
   ⇒ 40+ 特征；且沿用了特征重建后**已失效的 body 代理**（SWIG 代理问题）。
   ⇒ 现版本改为**一次草图装多个轮廓、一个特征干一批**（总特征 ~7）+ **每步重新获取 body**。
4. **别用 `taskkill /F` 强杀 Fusion**：本机两次强杀之后，Fusion 变成**每次启动 4 秒内崩溃**
   （`SafeModeCounter.json` 记到 1，即它已记录一次启动失败）⇒ 需要用户自己启动、按提示进安全模式/清缓存恢复。
5. 本机杂项（都有证据，不是猜）：Fusion 界面截图只能用 **Pillow**（`ImageGrab`）——
   PowerShell 的 `Add-Type` 被安全策略拦；`sleep` / `tee` 等 coreutils 在 Bash 工具里不可用；
   Windows 里的 `timeout.exe` 不是 GNU timeout。

## 6. 待定项（影响外壳，需拍板或实测）

| # | 待定 | 影响 |
| --- | --- | --- |
| H1 | **热插拔座高度实测**（现按 3.5 mm 假设） | 决定 `depth`；量一下手上插座即可 |

| H5 | 脚垫/倾角（是否做 3–5° 斜面） | 影响底板与打印摆放 |
| H6 | 分件接缝的对接结构（销/搭扣/共用螺丝） | 现为纯平面剖开，两件靠 PCB 与螺丝对齐 |
