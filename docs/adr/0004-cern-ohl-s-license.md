# 采用 CERN-OHL-S-2.0 开源许可证

项目面向社区复刻并可能小批量售卖。需要一份为硬件（而非纯软件）设计的许可证，明确覆盖设计文件与实物产品。

我们选择 CERN-OHL-S-2.0：强互惠，任何基于本设计的衍生产品在分发时必须以相同许可证公开完整设计文件。

## Considered Options

- MIT / CERN-OHL-P（宽松）：采用面更广，但无法阻止他人将设计闭源商用，与「社区共同受益」的意图不符。
- CERN-OHL-W（弱互惠）：允许作为组件集成进其他项目而不开源整个项目，互惠强度介于两者之间。

## Consequences

确保社区改进回流，符合开放平台愿景。代价是部分商业公司可能因此回避采用本设计。
